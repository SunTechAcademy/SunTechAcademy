# プロジェクト環境構築手順書

この手順書では、本プロジェクトの開発環境をローカル（自分のPC）に構築する手順を説明します。
未経験の方でも迷わず進められるよう、ステップバイステップで解説しています。

---

## 🛠️ 事前準備

開発を始める前に、以下のツールがインストールされているか確認してください。
まだインストールしていない場合は、リンク先からダウンロードしてインストールを完了させてください。

### 1. Git のインストール
コードを管理するためのツールです。
* **Windowsの方**: [Git for Windows](https://gitforwindows.org/) をインストールしてください。
* **Macの方**: ターミナルを開き、`git --version` と入力して実行してください。未インストールの場合は案内が表示されます。

### 2. Docker Desktop のインストール
アプリを動かすための「コンテナ」を管理するツールです。
* [Docker Desktop 公式サイト](https://www.docker.com/products/docker-desktop/) から、お使いのOS（Windows / Mac）に合わせてダウンロードし、インストールしてください。
* ⚠️ **重要**: インストール後、Docker Desktopのアプリを起動し、初期設定を完了させておいてください。

### 3. ソースコードエディタ（VS Code推奨）
プログラムを書くためのエディタです。
* [Visual Studio Code](https://code.visualstudio.com/) のインストールを推奨します。

---

## 🚀 Step 1：プロジェクトの複製（Git Clone）

プロジェクトのプログラム一式を、あなたのPCにダウンロード（クローン）します。

### 1. ターミナル（コマンドプロンプト）を開く
* **Windowsの方**: スタートメニューから **「コマンドプロンプト」** または **「Git Bash」** を開きます。
* **Macの方**: アプリケーション > ユーティリティから **「ターミナル」** を開きます。
