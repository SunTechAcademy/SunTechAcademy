# プロジェクト環境構築手順書

この手順書では、本プロジェクトの開発環境をローカル（自分のPC）に構築する手順を説明します。
未経験の方でも迷わず進められるよう、ステップバイステップで解説しています。

---

## 🛠️ 事前準備

開発を始める前に、以下のツールがインストールされ、正常に動作することを確認してください。

1. **Git** (`git --version` で確認)
2. **Docker Desktop** (アプリを起動し、バックグラウンドで動かしておくこと)
3. **VS Code** (推奨エディタ)

本プロジェクトではサーバー環境をDockerで一元管理しています。スクールで未導入だった方は、まず以下の手順でDocker Desktopを必ず準備してください。

### 1. インストール
* **Windows / Mac 共通**: [Docker Desktop 公式サイト](https://www.docker.com/products/docker-desktop/) から、自身のPCのOS・チップ（Macの場合はIntel版かApple Silicon版か）に合わせたインストーラーをダウンロードし、インストールを完了させてください。

### 2. 初回起動時のセットアップ（⚠️超重要）
インストール後、必ず一度 **Docker Desktop アプリを起動** してください。起動しないとこの後のコマンドがすべてエラーになります。
1. アプリを起動すると「Service Agreement（利用規約）」の画面が出るので、内容を確認して **[Accept]** をクリックします。
2. サインイン（ログイン）を求められますが、アカウント作成は不要です。 **[Continue without signing in]** （または後で設定）を選択してください。
3. アンケートやチュートリアルが表示された場合は、すべて **[Skip]** して大丈夫です。
4. アプリの左下のステータスランプが **緑色（Engine Running）** になれば準備完了です。

## 🚀 Step 1：プロジェクトの複製（Git Clone）

プロジェクトのプログラム一式を、あなたのPCにダウンロード（クローン）します。

### 1. ターミナル（コマンドプロンプト）を開く
* **Windowsの方**: スタートメニューから **「コマンドプロンプト」** または **「Git Bash」** を開きます。
* **Macの方**: アプリケーション > ユーティリティから **「ターミナル」** を開きます。

### 2. プロジェクトを保存したいフォルダへ移動する
例えば、デスクトップに保存したい場合は、以下のコマンドを入力して `Enter` キーを押します。
```bash
cd Desktop
```

### 3. クローンコマンドを実行する
以下のコマンドをコピーして貼り付け、`Enter` キーを押してください。
```bash
git clone [https://github.com/SunTechAcademy/SunTechAcademy.git](https://github.com/SunTechAcademy/SunTechAcademy.git)
```

### 4. クローンしたフォルダに移動
ダウンロードが完了したら、作成されたプロジェクトのフォルダの中に移動します。
```bash
cd SunTechAcademy
```

## ⚙️ Step 2：VS Codeで開き、環境設定ファイル（.env）を作る

ここからは、先ほどインストールした **VS Code（ソースコードエディタ）** を使って作業します。

### 1. プロジェクトをVS Codeで開く
現在のターミナル（黒い画面）で、以下のコマンドを入力して `Enter` キーを押してください。VS Codeが自動で起動します。
```bash
code .
```
(※もし起動しない場合は、普通にVS Codeアプリを開いて、「フォルダーを開く」からデスクトップの SunTechAcademy フォルダを選択してください)

### 2. .env ファイルを作成する
Laravelの設定ファイルを作ります。このプロジェクトでは src フォルダの中 に配置します。

1. VS Codeの左側のファイル一覧から、 src フォルダ をクリックして開きます。
2. src フォルダの中にある .env.example というファイルを探して右クリックします。
3. 「コピー」を選択し、同じ src フォルダ内で「貼り付け」をします。
4. コピーしてできたファイルの名前を .env に変更（リネーム）します。
(※ src/.env という位置関係になっていれば正解です！)

## 🐳 Step 3：Dockerコンテナの起動（最初の一回だけ）
アプリを動かすためのサーバー（Docker）を起動します。

### 1. VS Codeのターミナルを開く
VS Codeの画面上部メニューの 「ターミナル」 > 「新しいターミナル」 をクリックします。画面の下側に黒い画面が表示されます。

### 2. 起動コマンドを実行する
以下のコマンドをコピーして、VS Codeの下部に表示されたターミナルに貼り付け、Enter キーを押します。

```Bash
docker compose up -d
```
(※初回は必要なファイルのダウンロードや構築が始まるため、数分かかります。緑色の文字で Started や Running と表示されれば成功です！)
(※2回目以降は、このコマンドを打つ必要はありません。Docker Desktop（アプリ）の画面から起動・停止ができるようになります)

## 🛠️ Step 4：アプリの初期化処理（最初の一回だけ）
サーバーは立ち上がりましたが、まだ中身（ライブラリなど）が空っぽの状態です。動くようにするためのコマンドを順番に実行します。

### 1. PHPを動かしているコンテナ（部屋）の中に入る
VS Codeのターミナルで、以下のコマンドを実行します。
```Bash
docker compose exec app bash
```
(※左端の表示が root@xxxx:/var/www/html# のような表示に変われば、コンテナの中に入れた合図です)

### 2. ライブラリをインストールする
コンテナの中で、以下のコマンドを実行します。必要なプログラムがダウンロードされます。（1〜2分かかります）

```Bash
composer install
```

### 3. アプリの暗号化キーを生成する
セキュリティのための鍵を作ります。以下のコマンドを実行してください。

```Bash
php artisan key:generate
```
(※ Application key set successfully. と表示されればOKです)

### 4. データベースのテーブル（土台）を作る
データを保存するための表を作成します。以下のコマンドを実行してください。

```Bash
php artisan migrate
```
(※途中で何か聞かれたら、そのまま Enter キーを押すか yes と入力してください)

### 5. コンテナから脱出する
初期化が終わったので、以下のコマンドを入力して通常のターミナルに戻ります。

```Bash
exit
```

---

## 🌐 Step 5：動作確認

すべての準備が整いました！実際にブラウザでサイトが表示されるか確認しましょう。

### 1. ブラウザでアクセスする
Google Chromeなどのブラウザを開き、アドレスバーに以下のURLを入力して `Enter` キーを押します。
```text
http://localhost:8000
```

Laravelの初期画面、またはプロジェクトのトップ画面が表示されれば、環境構築は大成功です！🎉

💡 もし「Database connection refused」などのエラーが出たら？
src/.env ファイルを開き、データベースの接続設定が以下になっているか確認してください。

```text
DB_HOST=db （※ 127.0.0.1 ではなく db になっている必要があります）
DB_PORT=3306
DB_DATABASE=SunTechAcademy
DB_USERNAME=user
DB_PASSWORD=password
```

## 🔄 2回目以降の「起動」と「停止」の方法（日常の作業）
環境構築（Step 1〜4）は、最初の一回だけおこなえばOKです。
今日から開発を始めるときや、作業を終えるときは、ターミナルを使わず、Docker Desktop（アプリ）の画面から簡単に操作できます。

---

## 💻 作業を始めるとき（起動）
1. Docker Desktop アプリを起動します。
2. 画面の「Containers」タブを開くと、 suntechacademy という項目（コンテナグループ）が表示されています。
3. その右側にある ▶️（再生ボタン/Start） をクリックします。
4. アイコンが緑色（Running）になったら、ブラウザで http://localhost:8000 にアクセスして開発をスタートできます。

---

## 🛑 作業を終えるとき（停止）
1. Docker Desktop アプリを開きます。
2. suntechacademy の右側にある ⏹️（停止ボタン/Stop） をクリックします。
3. アイコンがグレー（Exited）になれば、パソコンの電力を消費せずに安全に終了できます。
